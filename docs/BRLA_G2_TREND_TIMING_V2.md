# BRLA-G2 趋势成熟度与入场时机协议 v2

**状态：FROZEN EXTENSION / RESEARCH AND PAPER ONLY**

本协议保留两阶段训练v1作为历史证据，新增 `emergenzix-brla-g2-trend-timing-v2`。元规则是：趋势方向决定是否值得关注，趋势时期决定是否值得进入；已有盈利仓位可以穿越中后期，但成熟趋势不允许增加新风险。

阶段一新增五个目标：趋势成熟度、剩余潜力、入场位置质量、反馈衰竭和后期追入风险。教师标签结合最近60根4小时K线的波段起点、波段年龄、方向扩展，以及隔离的7天未来结果。未来结果只生成标签，不进入观察。

阶段一数据集升级为 `emergenzix-brla-g2-stage1-timing-dataset-v2`，在v1样本哈希之上附加时机标签和新哈希；不覆盖v1证据，也不保存未来原始K线。

阶段二明确区分新开仓、持有旧仓、增加风险、减仓和退出。后期新开仓和成熟期加仓受到惩罚；早期高质量试探、盈利仓位在成熟期继续持有、收紧止损和衰竭时及时退出分别记账。奖励仍不能替代硬约束。

BRPM-G1新增硬门槛：成熟度达到70%时拒绝新开仓或加仓，但始终允许退出。首仓入场位置质量低于20%同样拒绝。已有仓位的持有、止损收紧和减仓由后续运行时接线继续实现。

这些阈值是待审计的初始研究协议，不是盈利结论。正式训练前必须在真实BTC历史上审计成熟度分布、入场质量分布、标签饱和和阶段覆盖。
