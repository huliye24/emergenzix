# BRPM-G1 仓位与风险预算地基

**状态：IMPLEMENTED / PAPER ONLY**

BRPM-G1 是确定性仓位风险引擎，不是收益预测模型。它接收 BRLA 的仓位建议，但只输出可供 BRGC 继续审查的 PAPER 目标，没有订单能力。

## 最坏损失

空头仓位以当前权益比例表示。止损处组合最坏损失包括：

```text
绝对仓位 × (止损价格 / 当前标记价格 - 1)
+ 全仓止损退出成本
+ 新增仓位的进入成本
```

止损必须高于当前标记价格。当前实现使用显式成本率，默认与 BRLA 环境一致为仓位变化的 0.15%。它是确定性的压力估计，不声称覆盖跳空、流动性枯竭或资金费率；这些风险需要后续加入额外缓冲。

## 风险预算和加仓规则

- 首仓必须有有效止损，最大 10%，且最坏损失不得超过共享战役风险预算。
- 加仓必须引用同一战役的完整、未篡改账本。
- 对空头而言，新止损必须低于上一止损且仍高于当前价格。
- 先按新止损计算原仓位风险，确认风险已经释放。
- 加仓成本和新增仓位计入后，组合总最坏损失必须严格低于上一笔账本风险。
- 加仓后仍不得超过战役预算和 50% 硬仓位上限。
- 本战役最坏损失与其他持仓已占用风险相加后，不得超过组合总风险预算。
- 趋势成熟度达到70%后禁止新开仓和增加风险；已有盈利仓位仍可持有、减仓或退出。
- 任一条件不确定时保持原仓位；完整退出始终允许。

## 风险释放账本

每次批准、保持、拒绝或退出都会生成不可变账本项，记录止损、加仓前后最坏损失、释放风险、剩余预算和拒绝原因。账本用 SHA-256 前向链接；顺序、前项哈希或内容遭到修改时，下一次分配 fail closed。

账本不等于交易流水，也不提供 TESTNET/LIVE 或自动晋级权限。下一步是把 BRPM-G1 接入 BRLA Gymnasium 环境，让所有仓位变化按本账本计算后再提交 BRGC。
