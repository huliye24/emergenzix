# BRLA-G2 阶段一监督学习数据集

**状态：IMPLEMENTED DATASET FOUNDATION / RESEARCH ONLY**

数据集协议 `emergenzix-brla-g2-stage1-dataset-v1` 将冻结的多时间尺度历史观察与连续秩序竞争标签连接起来，但两部分保持明确分离。

## 每条样本

历史输入包含15分钟、1小时、4小时和1日四个固定窗口。每根K线转换为四个因果特征：对数收益、对数高低区间、对数K线实体和相对窗口成交量中位数的对数比。归一化只使用当前历史窗口，不读取未来数据。

监督目标包含 `O(t)`、`N(t)`、`D(t)`、挑战持续率、变化速度、可信度和六阶段状态。标签由决策时刻之后固定7天窗口产生，但数据集样本不保存未来原始K线，只保存标签、组成项及未来窗口指纹。

## 样本边界

```text
历史180天及四尺度窗口结束 <= 决策时刻 < 未来7天标签窗口结束
```

修改未来K线可以改变标签，但不得改变历史观察哈希或特征张量。每条样本生成内容SHA-256，数据集再按有序样本哈希生成整体SHA-256。

## 数据用途

- `TRAIN + STAGE1_TRAIN`：允许训练秩序编码器。
- `DEVELOPMENT + DEVELOPMENT_EVAL`：只允许开发验证。
- `SEALED_TEST + FINAL_SEALED_EVAL`：要求模型已经冻结并获得外部封存授权。

用途与分区不匹配立即拒绝。数据集没有仓位、订单或自动晋级权限。

## 当前限制

本版本只包含OHLCV特征，尚未加入资金费率、OI、清算和盘口。教师标签仍是第一代确定性启发式，正式训练前需要生成标签分布报告，检查六阶段覆盖率、类别失衡、强度饱和与相邻样本重叠。
