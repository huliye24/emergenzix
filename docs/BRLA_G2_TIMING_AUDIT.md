# BRLA-G2 时机标签真实BTC审计

审计协议 `emergenzix-brla-g2-trend-timing-audit-v1` 在训练时机编码器前检查五项标签的边界饱和、形成/前中期/扩展/成熟/衰竭五个区间覆盖、优质入场样本、成熟度70%硬门槛的拦截比例以及实际可入场样本比例。

初始门槛为：每个成熟区间至少3条样本，任一标签在0.02或0.98边界的比例不超过35%，高质量入场至少3条且占比不低于10%，成熟门槛禁止的新开仓样本不超过50%，成熟度低于70%且入场质量不低于20%的样本至少3条且占比不低于10%。基础六阶段与分区审计也必须先通过。

审计只评价标签是否具备训练条件，不评价策略收益。失败结果不得通过降低阈值自动转为通过，也不授予仓位、订单或自动晋级权限。
