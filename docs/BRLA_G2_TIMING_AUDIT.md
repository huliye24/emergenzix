# BRLA-G2 时机标签真实BTC审计

审计协议 `emergenzix-brla-g2-trend-timing-audit-v1` 在训练时机编码器前检查五项标签的边界饱和、形成/前中期/扩展/成熟/衰竭五个区间覆盖、优质入场样本、成熟度70%硬门槛的拦截比例以及实际可入场样本比例。

初始门槛为：每个成熟区间至少3条样本，任一标签在0.02或0.98边界的比例不超过35%，高质量入场至少3条且占比不低于10%，成熟门槛禁止的新开仓样本不超过50%，成熟度低于70%且入场质量不低于20%的样本至少3条且占比不低于10%。基础六阶段与分区审计也必须先通过。

审计只评价标签是否具备训练条件，不评价策略收益。失败结果不得通过降低阈值自动转为通过，也不授予仓位、订单或自动晋级权限。

## 2026-11-11 真实BTC审计结果

云端使用2025-11-01至2026-11-03的BTCUSDT 15分钟历史数据，按7日步长取得26条样本。结论为 `NOT_READY_FOR_TIMING_ENCODER_TRAINING`：形成期1条、前中期9条、扩展期10条、成熟期6条、衰竭期0条，因此五区间覆盖不完整；高质量入场（质量不低于0.5）仅2条，占7.69%，低于最低要求。

五项连续标签没有出现严重边界饱和。只有入场位置质量在0.02以下占15.38%，仍低于35%上限；其余标签在0.02/0.98边界均为0。70%成熟门槛拦截6条，占23.08%，没有造成绝大多数样本禁止建仓；满足成熟度低于70%且入场质量不低于20%的样本为11条，占42.31%。

阻塞项来自样本结构而非70%门槛：缺少衰竭期、形成期不足、优质入场稀少，并且基础六阶段数据集审计尚未通过，开发集和封存测试集仍缺失。因此不得开始时机编码器训练，也不得调整门槛来自动获得通过。不可变摘要见 `research/training_runs/20261111-brla-g2-real-btc-timing-audit-v1.json`。
