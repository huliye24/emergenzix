# BRMG 统一场景与封存分区协议

**状态：IMPLEMENTED / PAPER RESEARCH ONLY**

BRMG v1 将三类市场路径转换为同一种不可变场景：Chronos 收盘价预测、BTC 历史熊市片段重采样、确定性极端压力路径。统一字段包括来源类型、生成器版本、来源指纹、标准 OHLCV、限制声明、内容哈希和场景哈希。

## 数据隔离

场景生成完成后一次性创建固定分区清单：

- `TRAIN`：只能用于参数学习。
- `DEVELOPMENT`：用于开发期比较和拒绝明显失败版本，不参与梯度更新。
- `SEALED_TEST`：仅在候选完全冻结后进行一次最终评估。

分区由场景哈希和开发盐确定，不按收益人工挑选。相同 OHLCV 内容即使换名称或生成器也不能跨分区。清单记录每个场景和路径内容的 SHA-256；缺失、增加或修改场景都会 fail closed。

最终测试需要外部保存的至少 32 字符访问令牌。仓库和清单只保存令牌哈希，不能把令牌提交到 Git。训练器与开发验证器不接受该令牌，也不能请求 `SEALED_TEST` 分区。

## 边界

统一场景不代表三种来源具有相同真实性。Chronos 的成交量与影线是代理；历史重采样破坏真实连续路径；极端压力路径不是概率预测。这些限制保留在每个场景中。所有场景均为 PAPER 研究资产，不授予自动晋级或订单权限。
